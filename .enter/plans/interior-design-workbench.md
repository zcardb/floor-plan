## Context
根据你提供的完整 HTML/JavaScript 参考，在现有 React + Vite + TypeScript 项目中实现可实际使用的户型装修工作台，而不是展示页。已确认：完整 2D 编辑与 3D 漫游、家具库、材料估算、导入导出、邮箱密码注册／登录、云端保存；界面仅简体中文。另明确支持游客模式：无需登录即可直接调整设计、下载 2D 图片，并调整 3D 方向后下载当前视角截图。

当前项目只有占位首页，没有装修业务或已实现的认证流程。规划阶段只生成此文件；批准后再连接 Enter Cloud、安装依赖及修改应用。

## 推荐实现
### 界面与布局
- 保留参考的米色图纸、陶土色强调、深青辅助色和专业 CAD 气质，不添加营销首页。
- 顶部拆成品牌／2D-3D／文件与账户栏，以及当前模式的工具栏，避免大量按钮挤在同一行。
- 桌面左侧 236px 家具库、中央画布、右侧 300px 属性／统计，下方状态栏；支持收起两侧面板。
- ≤1100px 使用互斥侧边抽屉，390px 手机显示紧凑工具菜单、浮动选中工具条和漫游摇杆。保留页面缩放的无障碍能力，只在画布拦截编辑手势。
- 在 `src/index.css`、`tailwind.config.ts` 中定义 HSL 语义色、字体、材质、选中与危险状态；复用 Button、Input、Dialog、Sheet、DropdownMenu、Slider、Tooltip 与 Sonner。图标使用 lucide-react。主色文字组合校验 WCAG AA，不直接复制参考中对比不足的灰色。

### 共享数据与 2D 编辑
- 将参考的 WALLS、WINS、DOORS、SLIDES、ROOMS、MATS、LIB、defaultFurniture 整理为有类型的业务数据；这是用户明确提供的初始设计与目录，不是伪造云端数据。
- 同一设计状态包含 furniture、rooms、demolished、measures，并增加版本号；2D、3D、预算和云端保存共用此状态。
- 迁移参考的 area、perim、bbox、aabb、norm、snapMove、snapPoint、pushOut 计算；房间家具归属使用点在多边形内判断，避免异形餐厅／过道的包围盒误判。
- SVG 分层绘制材质地面、家具图例、墙体、门窗、房间文字、尺寸链、测量与选择手柄；支持平移、滚轮／双指缩放、适应、1:60／1:100 显示比例。
- 家具支持点击／拖入、拖动、旋转、尺寸手柄、名称／尺寸／位置／颜色属性编辑、复制／删除、前后层级、10mm 网格与贴墙吸附。
- 测量支持两点／拖线及 Shift 轴向约束；非承重墙可标记拆除／恢复，承重墙与外墙不可拆。界面明确这是方案标记，不是结构安全评估，实际拆改须专业确认。
- 每次完成的编辑进入撤销记录，连续拖动只生成一个记录，历史上限 150；撤销／重做不包含镜头与纯 UI 操作。实现参考快捷键，表单输入时不触发画布快捷键。
- 总览与房间面板显示净面积、周长、家具数、拆除长度；飘窗不计入套内面积，地面估价按材料单价 × 面积 × 1.05。明确仅为地面材料参考，不是完整施工报价。

### 3D 场景
- 安装 npm 依赖 `three` 及匹配类型；不用 CDN importmap，也不用 iframe 嵌入原始 HTML。
- 用户首次切换到 3D 才动态加载 Three.js 场景，2D 首屏同步可用；加载失败显示可重试提示并可继续使用 2D。
- 共用毫米数据转换为米，层高 2.8m；生成真实立体墙、门窗、飘窗、地面纹理及与目录对应的家具模型，不用静态图片冒充 3D。
- 支持鸟瞰旋转／平移／缩放、斜视／俯视、全高／1.2m 剖切、房间定位、家具／标签开关、日照与夜景。
- 支持选取与拖放家具、房间属性编辑，2D／3D 双向同步；门扇可开关。
- 漫游使用桌面 WASD／鼠标视角与触屏摇杆／拖动视角，墙体与门扇碰撞使用实际门宽。退出漫游／切回 2D 清理按键与指针锁定。
- 2D／3D 切换采用对齐俯视到斜视的过渡；尊重 reduced-motion。拖动只更新受影响对象，不重建全场景；退出／卸载释放渲染器、几何、纹理、监听和动画循环。

### 登录与云端保存
- 批准后连接本项目专属 Enter Cloud；如已存在连接则复用，不切换已有后端。先检查拟用表结构，保留所有现有表与数据，尤其不修改旧 profiles 业务。
- 邮箱密码注册、登录、退出与会话恢复；按认证规范配置注册及邮箱自动确认。用 onAuthStateChange 保存 session 与 user，监听先于 getSession，回调内不直接发起异步数据库调用。
- 推荐最小保存范围：每个账号一个当前装修方案，不额外增加项目管理、协作或分享功能。使用独立 `interior_design_plans` 表：id、owner_id（唯一）、name、schema_version、state(jsonb)、revision、created_at、updated_at。
- 新表迁移中同时启用 RLS，SELECT／INSERT／UPDATE／DELETE 均限定 `auth.uid() = owner_id`；数据库约束与版本检查保护方案，绝不依赖前端隐藏按钮来授权。迁移后复查策略。
- `/` 默认直接进入游客工作台，不设登录门槛。游客可完整使用 2D／3D 编辑、家具库、测量、材质、预算、撤销重做及文件导入导出；首次显示参考方案，后续可恢复本机游客草稿。
- 游客无需登录即可下载 2D PNG；可通过鸟瞰旋转、斜视、俯视或漫游调整 3D 方向，下载当前相机视角 PNG，不强制重置镜头或改用固定角度。下载保存到用户设备，不上传云端。
- 游客状态与云端保存分别标明“游客模式／本机草稿”及“登录后云端保存”，不把本机保存显示为云端已保存。仅云端保存操作引导注册／登录，取消登录不打断编辑或下载。
- 账号方案先加载成功才允许自动写入；从游客登录后，如已有云端方案，让用户明确选择打开云端或将当前游客方案保存为当前账号方案，已有访客草稿不静默覆盖云端方案。
- 已登录的完成编辑防抖自动保存，并提供立即保存；状态区分正在保存、已保存、未保存／失败。失败保留当前草稿并可重试，不能显示假成功。
- 本地草稿按账号隔离，作为网络失败的恢复副本而非云端替代；退出／切账号取消待写任务和旧请求，避免跨账号写入。保存按 revision 条件更新，检测其它窗口改动后提示，不静默覆盖。

### 文件与平台兼容
- 支持 2D PNG、当前 3D PNG、方案 JSON 导出，以及原参考 JSON 导入（缺少版本字段时升级为当前格式）。
- 导入前严格验证类型、有限坐标、正尺寸、材料／房间／墙体标识及允许拆除类型；非法文件不改变现有状态；有效导入、清空家具和重置均可撤销。清空／重置先确认。
- 屏幕比例注明按 CSS 像素估算，物理显示比例取决于设备；导出不带选中手柄。
- 不新增 AI、支付、多语言或统计采集功能。保留已有 analytics 平台契约、i18n 初始化、路由注册和 Vite 插件；业务界面固定简体中文，无语言切换入口。
