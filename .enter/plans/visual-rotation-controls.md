## Context
当前 Visual 家具工具条的旋转按钮只有图标，「尺寸与位置」弹窗仅提供角度输入，详细属性中的按钮仅写「旋转」。统一为明确的「旋转 90°」按钮，并在其右侧显示可手动填写的当前角度，覆盖楼梯及所有已有旋转能力的家具对象。

「默认 90°」指每次点击按钮相对当前角度顺时针增加 90°，不是把对象初始角度或现有方案角度改成 90°。输入框表示绝对角度，打开面板不改变对象。

## 推荐实现
新增小型共享 `RotationControls`，采用现有 `Button`、`Input`、`Label` 和 `RotateCw` 图标。左侧按钮始终显示「旋转 90°」，右侧为带度数标签的角度输入框；沿用当前颜色、边框、焦点和控件尺寸设计，不重设计其它工具。

复用 `Workbench.rotate(angle = 90)`、`editSelection` / `norm`、`createSizeTransaction` 和 `SizeFields` 的输入即时预览、失焦提交、Enter 和 Escape 行为。按钮操作前先结束有效输入事务，非法草稿恢复后再旋转，避免未结束预览覆盖按钮结果；外部按钮、快捷键、拖动旋转、撤销或重做后，非编辑中的角度输入与当前模型同步。保持输入时的草稿，不在每次预览重渲染时打断输入。

墙、门窗、房间不新增自由旋转功能；门开向、尺寸米制换算、家具位置及颜色等行为保持原样。不涉及数据库或后端改动，不合并其它待审批方案。

## 关键文件
- 新增 `src/features/interior/components/RotationControls.tsx`：共享旋转按钮与角度输入布局。
- `src/features/interior/components/SizeFields.tsx`：家具旋转字段改为跨两列的组合控件，保留其它尺寸字段与事务语义。
- `src/features/interior/components/SelectionEditor.tsx`：工具条原旋转图标入口改为按钮加右侧角度输入，接入共享控件；弹窗复用相同布局。
- `src/features/interior/components/PropertyPanel.tsx`：详细属性使用相同旋转组合，去除重复的孤立旋转字段／按钮，保留复制、删除等动作。
- `src/index.css`：补充共享旋转行布局，使用既有语义 token，限制工具条输入宽度并兼容窄屏。
- 相关组件测试与 `src/features/interior/model/sizeTransaction.test.ts`：复用现有 Vitest 测试方式补充旋转交互与事务回归。

## Implementation checklist
- [ ] 新建共享旋转控件，DOM 顺序为「旋转 90°」按钮、当前角度输入框，均支持键盘操作及可访问标签。
- [ ] 所有已有家具旋转入口统一显示组合控件，包括 Visual 工具条、尺寸弹窗及详细属性；楼梯与其它家具遵循相同规则。
- [ ] 按钮在当前角度上增加 90°，通过现有归一化规则更新；手动填写角度设置绝对角度，不做米制换算。
- [ ] 旋转角度有效输入即时预览，失焦／Enter 提交；Escape 取消，非法输入不写入模型，按钮与输入事务不互相覆盖。
- [ ] 输入框在外部旋转、撤销／重做及切换选中对象后显示对应模型角度，打开控件不修改角度。
- [ ] 共享旋转行在弹窗中跨两列并保持左按钮右输入；工具条窄屏布局不截断输入和按钮。
- [ ] 保留墙体锁定、门开向、其它尺寸字段、现有旋转快捷键及方案数据。

## Verification checklist
- [ ] 正向：楼梯和普通家具从 0° 点击至 90°、180°；从 30° 点击至 120°，右侧输入与画布一致。
- [ ] 正向：在各入口手动填写 45°，画布和其它入口同步；有效编辑与一次按钮旋转可分别撤销／重做。
- [ ] 默认／负向：打开当前为 0° 或 45° 的对象不改变角度；墙、门窗、房间不出现新增旋转控件；空值及非法数值不持久化。
- [ ] 边界：270° 再点击返回 0°；手填负数及超过 360° 的数值沿用 `norm`；有效输入后点击按钮、非法输入后点击按钮和 Escape 均不导致旧草稿覆盖新角度。
- [ ] 同步：尺寸弹窗保持打开时，从工具条／快捷键／拖动旋转修改角度，或切换对象、撤销／重做，非编辑中的输入框刷新到当前角度。
- [ ] 在实际受影响的编辑页面，以 `mobile_390` 和 `desktop_1280` 检查旋转组合控件（用户未指定设备，采用这两个视口），确认按钮在左、输入在右，无遮挡或溢出；若无法进入对应交互态，明确标注未验证。
- [ ] 执行 `pnpm exec vitest run src/features/interior/components src/features/interior/model/sizeTransaction.test.ts src/features/interior/model/lengthUnits.test.ts`、`pnpm check` 和 `pnpm run build`，记录结果。
