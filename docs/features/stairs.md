# 楼梯（STAIR）— 强制

楼梯是一种家具（`type === 'stairs'`），但平面图样、参数和图层都与普通家具不同。相关文件：

| 文件 | 职责 |
| --- | --- |
| `model/types.ts` | `StairForm`、`StairSpec`、`Furniture.stair`、`LibraryItem.stair` |
| `model/stairs.ts` | 预设、参数推导、平面几何（`stairLayout`）、规范提示（`stairMetrics`） |
| `components/StairPlan.tsx` | 把几何画成 SVG 图样 |
| `components/StairEditor.tsx` | 专属编辑面板（类别、各跑宽、踏步数、方向、转向） |
| `data/catalog.ts` | 素材库里引入 `stairLibrary` |

## 1. 类别与参数

- 五种类别：`straight` 直跑、`l` L 型、`u` U 型、`triple` 三跑、`spiral` 螺旋。
- 参数：`flightWidth` / `flightWidths`（各跑梯段宽）、`flightLengths`（各跑梯段长）、`wellGap`（梯井净宽，仅 U 型）、`steps`（踏步数）、`treadDepth`（踏面宽）、`riserHeight`（踏步高）、`stepsManual`（踏步数是否手动）、`reverse`（行走方向反转）、`hand`（`left` / `right`，仅 L / U / 三跑）。
- **行业标准默认值**（`STAIR_DEFAULTS`）：踏步高 175 mm、踏面宽 280 mm，即住宅套内常用值。梯段长按 `该跑踏步数 × 踏面宽` 推导（`stairStandardLengths`）。
- **踏步数自动推算**：`stairSteps(层高, 踏步高)` = 层高 ÷ 踏步高，取整并夹到 3–40 级。放置楼梯、切换类别、改踏步高或改层高时都会重算；用户手动改过之后（`stepsManual`）不再自动变，界面上提供「按层高算」恢复。
- **外框由梯段长推导**（`stairSizeOf`，单位 mm）：
  - 直跑：`W = 梯段宽`，`D = 梯段长`
  - L 型：`W = 第 1 跑宽 + 第 2 跑长`，`D = 第 2 跑宽 + 第 1 跑长`
  - U 型：`W = 第 1 跑宽 + 梯井 + 第 2 跑宽`，`D = 平台进深（取两跑宽的较大者）+ max(两跑长)`
  - 三跑：`W = 第 1 跑宽 + 第 2 跑长 + 第 3 跑宽`，`D = 第 2 跑宽 + max(第 1、3 跑长)`
  - 螺旋：由踏面宽（距内侧 0.25 m 量）与踏步数反推，`W = D = 2 × (中柱半径 + 梯段宽)`
- **梯井**：U 型（双跑）楼梯两跑梯段之间的竖向空档，平面上夹在左右两跑中间。默认 0.20 m（`STAIR_WELL_GAP`），可在 0–1.00 m 之间调；GB 50096 规定梯井净宽大于 0.11 m 时须做防止儿童攀滑的措施。旧 U 型数据没有 `wellGap` 时，首次编辑从当前外框量出，不改外框。
- **外框与梯段双向一致**：外框由梯段推导；在「尺寸与位置」里直接改外框时，`fitStairToBox` 按新外框反推各跑宽 / 长（U 型保留梯井、两跑等比缩放；直跑即改梯段宽与梯段长；螺旋按外径反推踏面宽并保持正方形）。不允许出现“改了外框、调细节后外框跳回去”。
- **外框说明**：编辑面板必须列出外框宽 / 深是由哪些尺寸相加而来（`stairBoxTerms`），例如 `第 1 跑宽 1.00 + 梯井 0.20 + 第 2 跑宽 1.00 = 2.20 m`。
- **旧数据兼容**：没有 `stair` 字段的楼梯按 `{ straight, flightWidth: w, steps: 12 }` 处理（`stairSpec`），图样与历史一致。有 `stair` 但没有 `flightLengths` 时，按外框等分（与上一版行为一致）。
- 校验（`validStairSpec`）：`steps` 为 3–40 的整数；梯段宽 300–5000 mm；梯段长 300–20000 mm；梯井 0–1000 mm 且只允许出现在 U 型；踏面宽 150–400 mm；踏步高 100–250 mm；各数组长度必须等于跑数；`hand` 只能是 `left` 或 `right`；`stepsManual` 必须是布尔值。

## 2. 平面图样必须画出的内容（GB/T 50104）

1. 踏步线、平台分界线、梯井边线（`lines`）
2. 行走线（各跑中线的折线）加终点箭头（`walk`、`arrow`）
3. 起步圆点（`start`、`startRadius`）
4. 「上」字（`label`、`labelSize`），放在第一跑右手侧
5. 第一跑上的 45° 折断线（`breakLine`）
6. 外框轮廓（`outline`：矩形、多边形或圆）

- 几何全部由 `stairLayout(spec, w, d)` 计算，组件只负责画，不要在组件里写几何。
- 局部坐标：外框中心为原点，起步在下方 +y，向 −y 上行。
- 各跑宽必须夹到外框能容纳的范围内，任何外框尺寸都不能产生负尺寸或 `NaN`。U 型两跑不等长时外框用多边形（短的那跑末端之后不是楼梯），等长时用矩形。
- `reverse` 只改行走方向与标记（起点、箭头、「上」字、折断线换到另一头），踏步线和外框不变。
- `hand: 'left'` 直接镜像坐标（`x` 取负），**不要**用 `scale(-1 1)` 变换：镜像变换会把「上」字变成反字，导出时也会违反“不使用负比例”的规定。

## 3. 规范提示（`stairMetrics`）

依据 GB 50096 套内楼梯：梯段净宽 ≥ 0.75 m、踏步宽 ≥ 0.22 m、踏步高 ≤ 0.20 m；扇形踏步在距内侧 0.25 m 处量踏步宽。
只提示、不拦截，界面上用警告样式显示。踏步高 = `Design.height` ÷ 踏步数。

## 3.1 编辑面板

`StairEditor.tsx` 必须提供：类别卡片（缩略图按该类别标准梯段长绘制）、每跑“宽 / 长”、梯井宽（U 型）及其说明、外框组成算式、踏步数（自动 / 手动标记 + 恢复自动）、踏面宽、踏步高、行走方向、转向（多跑时）、推导结果（外框、实际踏面宽、实际踏步高、踏步数）与规范提示。

面板尺寸（`index.css` 的 `.stair-popover`）：宽 360px、`max-height: min(72vh, 520px)` 且内部滚动，`side="right"`，不得盖住正在编辑的楼梯。

## 4. 导出

- 楼梯在单独的 `STAIRS` 图层（天正 `STAIR` / AIA `A-FLOR-STRS`），不与普通家具混在 `FURNITURE`。见 `drawing-export.md`。
- 图块名前缀 `STAIR_`，签名包含整个 `stair` 对象，所以类别、各跑宽、方向、转向不同的楼梯不会共用一个块。
- 螺旋楼梯的外圆与中柱要导出成 CIRCLE 而不是折线。
- 「上」字是模型空间的 TEXT（不进块），角度经过 `readableRotation()`。
- 3D 视图目前按普通家具处理，没有按类别和踏步数生成台阶，这是已知缺口。

## 5. 成本与分类

- 楼梯算**硬装**，分类名为「楼梯」（`STAIR_CATEGORY`），按件计价（`furniturePrices` 价格组）。
- 判断一律用 `isStairs()`（按 `type` 判断），这样旧数据和账号里的副本也能正确归类。
- 房内的楼梯计入该房间的硬装；全屋明细里单独成「楼梯」一行。

## 6. 必须有的测试

`src/features/interior/components/stairs.test.tsx`：

- 五种类别都能渲染，含「上」字、箭头、起步点、折断线
- 踏步线数量随踏步数变化；旧数据仍是 11 条
- 梯段长 / 踏面宽 / 踏步高改变时外框与梯段长按规则联动；踏步数自动与手动的切换
- 在尺寸里改外框后再调细节，外框不回退（U 型 1.80 m 案例）；梯井可调且越界被拒绝
- 边缘外框（1 m）与 20 m 梯段长都不出现 NaN 或负尺寸
- 反转后起点、箭头、「上」字对调且踏步线不变
- 左转是镜像、没有 `transform` 文字
- 各跑宽生效、平台随之变化
- 边界：外框 1 m、每跑宽 3 m 时不出现 `NaN` 或负尺寸
- 校验拒绝非法 `steps` / `flightWidths` / `hand` / `reverse`
