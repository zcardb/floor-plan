# 功能规范（Features）

每个功能一份规范，记录**必须遵守**的规则：数据约定、行业规范、导出要求和必备测试。只属于一个模块的规范放在该模块目录的 `README.md`；跨多个模块的放在这里。新增或修改功能时：

1. 先读对应的规范，按其中的规则实现；
2. 规则有变化时，同一次改动里更新规范；
3. 新功能如果有需要长期遵守的约束，就补一份规范，并加到下表里。

| 规范 | 范围 |
| --- | --- |
| [lib/drawing](../../src/lib/drawing/README.md) | SVG / PDF / DXF 导出，以及 CAD / DXF 行业规范（图层、图块、文字、尺寸）。**所有家具和设计元素都要遵守** |
| [stairs.md](./stairs.md) | 楼梯：类别与参数、平面图样（GB/T 50104）、规范提示（GB 50096）、导出、成本分类 |
| [scene-3d](../../src/features/scene-3d/README.md) | 3D 场景：家具精修模型与装修风格配色、材质与环境反射、地面贴图、墙门窗配色、必备测试 |
| [decor-styles](../../src/features/decor-styles/README.md) | 装修风格：作用范围（只影响 3D）、角色配色结构、100 套内置风格与我的风格、外部 3D 素材导入边界 |
| [report](../../src/features/report/README.md) | 方案报告：预览与多页 A4 PDF（平面图 + 关键信息 / 目录 + 预算 / 清单页）、数据来源与不变量、PDF 中文字体补齐、导出出口、必备测试 |
